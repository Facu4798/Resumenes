# Redes neuronales
Una red neuronal es un sistema de procesamiento paralelo, masivo y distribuido, formado por unidades simples que tienen la capacidad de adquirir conocimiento a través de un proceso de entrenamiento, y almacenar este conocimiento para su uso posterior.
- Redes perceptrón multicapa (MLP)
- Redes convolucionales (CNN)
- Redes recurrentes (RNN)
- Transformers
